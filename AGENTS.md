# AGENTS.md

AI agents working on this repository must:

1. Read `LLMS.md` first.
2. Follow `docs/SAFETY_RULES.md`.
3. Use `docs/COMMANDS.md` for allowed commands.
4. Keep the project local-first, read-only/dry-run/review-only.
5. Never move, rename, delete, overwrite, or reorganize source archive files.
6. Never touch personal files, cloud APIs for personal content, n8n runtime, MCP/filesystem agents, installs, or secrets unless explicitly approved.
7. ChatGPT is the primary orchestrator and implementer using only available authorized tools. Cursor is optional support, only if explicitly delegated by the user; verify clean/aligned workspace before any local handoff.
8. Use PowerShell for user-local Windows commands.
9. Never auto-open HTML reports unless explicitly requested by the user.

Keep changes small and avoid duplicated Markdown documentation.
